# Empty

What a list shows when it has nothing: a picture, a title, a sentence, and what to do.

```twig {"preview":true}
<twig:Empty>
    <twig:Empty:Header>
        <twig:Empty:Title>No event yet</twig:Empty:Title>
        <twig:Empty:Description>The next ones will be listed here.</twig:Empty:Description>
    </twig:Empty:Header>
    <twig:Empty:Content><twig:Button>Add an event</twig:Button></twig:Empty:Content>
</twig:Empty>
```
