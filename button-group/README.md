# ButtonGroup

Buttons that belong together, joined: a view switcher, the previous and next periods.

```twig {"preview":true}
<twig:ButtonGroup aria-label="View">
    <twig:Button variant="outline">Day</twig:Button>
    <twig:Button variant="outline">Week</twig:Button>
</twig:ButtonGroup>
```

## Installation

::: installation

## Usage

```twig
<twig:ButtonGroup aria-label="View">
    <twig:Button variant="outline">Day</twig:Button>
    <twig:Button variant="outline">Week</twig:Button>
</twig:ButtonGroup>
```

## Accessibility

Name the group with `aria-label`: the name says what its buttons do together.
