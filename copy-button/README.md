# CopyButton

A button that copies a text, given or read from another element, and says so.

```twig {"preview":true}
<twig:CopyButton text="https://example.com/invite" />
```

## Installation

::: installation

## Usage

```twig
<twig:CopyButton text="https://example.com/invite" />
```

## Accessibility

What happened is written on the button and in a polite live region. The button stays hidden where the browser offers no clipboard, which needs a secure context.
