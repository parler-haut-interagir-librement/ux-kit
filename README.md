# ux-kit

PHIL UX kit for the Symfony UX Toolkit: the same recipes as the Shadcn kit, styled with phil-ux, installed with `ux:install --kit=github.com/parler-haut-interagir-librement/ux-kit`.

This repository is split from the PHIL monorepo, where it is developed; changes are made there.
